Pipeline summary

Scoring service — inputs & outputs

Returns the 8-week forecast (mean, 80% interval, seasonal-naive) and the risk assessment for one SKU or a batch. Optional overrides re-score with a different inventory position.

GET  /api/health
GET  /api/score?sku=SKU012
GET  /api/score?sku=SKU012&lead_time_days=21&on_hand=30
GET  /api/score?sku=SKU012,SKU020,SKU026
GET  /api/score?all=true
POST /api/score   {"skus":["SKU012","SKU020"],
                   "overrides":{"lead_time_days":14}}

Errors are explicit JSON with HTTP 400/404/405 — never a crash: unknown SKU, non-numeric override, empty request, bad JSON body.
